## Задача 1 (КР 2)

$y'' + 4y = \frac{8}{\cos^2 x}$

**Соотв ОЛДУ:**
$y'' + 4y = 0$
$\lambda^2 + 4 = 0$
$\lambda^2 = -4$
$\lambda_{1,2} = \pm 2i$

**ФСР:**  $\cos 2x, \sin 2x$
$y_{о.о.} = C_1 \cos 2x + C_2 \sin 2x$

**Возвр к НЛДУ:**
$y_{о.н.} = C_1(x) \cos 2x + C_2(x) \sin 2x$

$\begin{cases} \cos 2x \cdot C_1' + \sin 2x \cdot C_2' = 0 \\ (\cos 2x)' \cdot C_1' + (\sin 2x)' \cdot C_2' = \frac{8}{\cos^2 x} \end{cases}$

$\begin{cases} \cos 2x \cdot C_1' + \sin 2x \cdot C_2' = 0 \\ -2\sin 2x \cdot C_1' + 2\cos 2x \cdot C_2' = \frac{8}{\cos^2 x} \end{cases}$

$\Delta(x) = \begin{vmatrix} \cos 2x & \sin 2x \\ -2\sin 2x & 2\cos 2x \end{vmatrix} = 2\cos^2 2x + 2\sin^2 2x = 2$
==^ точно "(x)"?==

$\Delta_1 = \begin{vmatrix} 0 & \sin 2x \\ \frac{8}{\cos^2 x} & 2\cos 2x \end{vmatrix} = 0-\frac{8\sin 2x}{\cos^2 x} = -\frac{16\sin x \cos x}{\cos^2 x} = -16 \text{tg}x$

$\Delta_2 = \begin{vmatrix} \cos 2x & 0 \\ -2\sin 2x & \frac{8}{\cos^2 x} \end{vmatrix} = \frac{8\cos 2x}{\cos^2 x}+0 = \frac{8(2\cos^2 x - 1)}{\cos^2 x} = 16 - \frac{8}{\cos^2 x}$

$\begin{cases} C_1' = \frac{\Delta_1}{\Delta} = -8 \text{tg}x = -8 \frac{\text{sin}x}{\text{cos}x} \\ C_2' = \frac{\Delta_2}{\Delta} = 8 - \frac{4}{\cos^2 x} \end{cases}$

$\int -8 \frac{\text{sin}x}{\text{cos}x} \, dx + D_1 = \int 8 \frac{d \, \text{cos}x}{\text{cos}x} + D_1 = 8\ln|\cos x| + D_1$
$\int (8 - \frac{4}{\cos^2 x}) \, dx + D_2 = 8x - 4\text{tg}x + D_2$

$\begin{cases} C_1(x) = 8\ln|\cos x| + D_1 \\ C_2(x) = 8x - 4\text{tg}x + D_2 \end{cases}$

$y_{о.н.} = (8\ln|\cos x| + D_1)\cos 2x + (8x - 4\text{tg}x + D_2)\sin 2x$

## Задача 2 (КР 2)

$y'' - 3y' + 2y = 52\cos 3x$

**Соотв ОЛДУ:**
$y'' - 3y' + 2y = 0$
$\lambda^2 - 3\lambda + 2 = 0$
$(\lambda - 1)(\lambda - 2) = 0$
$\lambda_1 = 1, \lambda_2 = 2$

**ФСР:**  $e^x, e^{2x}$
$y_{о.о.} = C_1 e^x + C_2 e^{2x}$

**Возвр к НЛДУ:**
$f(x) = 52\cos 3x = e^{0x}(52\cos 3x + 0\sin 3x)$
$\alpha = 0, \beta = 3, P(x) = 52, Q(x) = 0$
$\alpha + \beta i = 3i \Rightarrow S = 0$
$\text{deg}(R) = \text{deg}(T) = \max\{\text{deg}(P), \text{deg}(Q)\} = 0$
$R(x) = A, T(x) = B$
$y_{ч.н.} = x^0 e^{0x}(A\cos 3x + B\sin 3x) = A\cos 3x + B\sin 3x$

$y_{ч.н.}'' - 3y_{ч.н.}' + 2y_{ч.н.} = 52\cos 3x$

$y_{ч.н.}' = (A\cos 3x + B\sin 3x)' = -3A\sin 3x + 3B\cos 3x$
$y_{ч.н.}'' = (A\cos 3x + B\sin 3x)'' = (-3A\sin 3x + 3B\cos 3x)' =$
$= -9A\cos 3x - 9B\sin 3x$

**Подставим:**
$(-9A\cos 3x - 9B\sin 3x) - 3(-3A\sin 3x + 3B\cos 3x) +$
$+ 2(A\cos 3x + B\sin 3x) = 52\cos 3x = 0\sin 3x$

$(-9A - 9B + 2A)\cos 3x + (-9B + 9A + 2B)\sin 3x = 52\cos 3x + 0\sin 3x$

$\begin{cases} -7A - 9B = 52 \\ 9A - 7B = 0 \end{cases} \Leftrightarrow \begin{cases} -7A - 9(\frac{9}{7}A) = 52 \\ B = \frac{9}{7}A \end{cases} \Leftrightarrow$

$\Leftrightarrow \begin{cases} -\frac{130}{7}A = 52 \\ B = \frac{9}{7}A \end{cases} \Leftrightarrow \begin{cases} A = -\frac{14}{5} \\ B = -\frac{18}{5} \end{cases}$

$y_{ч.н.} = -\frac{14}{5}\cos 3x - \frac{18}{5}\sin 3x$
$y_{о.н.} = y_{о.о.} + y_{ч.н.}$
$y_{о.н.} = C_1 e^x + C_2 e^{2x} -\frac{14}{5}\cos 3x - \frac{18}{5}\sin 3x$

## Задача 1 (КР 3)

$\begin{cases} y'' + 2y' + y = 3e^{-x}\sqrt{x+1} \\ y(0) = \frac{4}{5} \\ y'(0) = 2 \end{cases}$

$y'' + 2y' + y = 3e^{-x}\sqrt{x+1}$

**Соотв ОЛДУ:**
$y'' + 2y' + y = 0$
$\lambda^2 + 2\lambda + 1 = 0$
$(\lambda + 1)^2 = 0$
$\lambda_{1,2} = -1$

**ФСР:**  $e^{-x}, x e^{-x}$
$y_{о.о.} = C_1 e^{-x} + C_2 x e^{-x}$

**Возвр к НЛДУ:**
$y_{о.н.} = C_1(x) e^{-x} + C_2(x) x e^{-x}$

$\begin{cases} e^{-x} C_1' + x e^{-x} C_2' = 0 \\ (e^{-x})' C_1' + (x e^{-x})' C_2' = 3e^{-x}\sqrt{x+1} \end{cases}$

$\begin{cases} e^{-x} C_1' + x e^{-x} C_2' = 0 \\ -e^{-x} C_1' + (e^{-x} - x e^{-x}) C_2' = 3e^{-x}\sqrt{x+1} \end{cases} \mkern10mu  \begin{array}{c} \\[-1ex] \text{\huge ⤶} \end{array} +$
==^ \*закруглённая стрелка от верхнего уравнения к нижнему==

$e^{-x} C_2' = 3e^{-x}\sqrt{x+1}$
$C_2' = 3\sqrt{x+1}$
$C_2 = \int 3(x+1)^{1/2} \, dx + D_2 = 2(x+1)^{3/2} + D_2$

$C_1' = -x C_2' = -3x\sqrt{x+1}$
$C_1 = \int -3x\sqrt{x+1} dx + D_1 = -3\int (x+1-1)\sqrt{x+1} d(x+1) + D_1 =$
$= -3(\frac{2}{5}(x+1)^{5/2} - \frac{2}{3}(x+1)^{3/2}) + D_1 = -\frac{6}{5}(x+1)^{5/2} + 2(x+1)^{3/2} + D_1$

$y_{о.н.} = (-\frac{6}{5}(x+1)^{5/2} + 2(x+1)^{3/2} + D_1)e^{-x} + (2(x+1)^{3/2} + D_2)xe^{-x} =$
$= e^{-x} (D_1 + D_2x + 2(x+1)^{3/2} + 2x(x+1)^{3/2} - \frac{6}{5}(x+1)^{5/2}) =$
$= e^{-x} (D_1 + D_2x + 2(x+1)^{3/2}(1 + x) - \frac{6}{5}(x+1)^{5/2}) =$
$= e^{-x} (D_1 + D_2x + 2(x+1)^{5/2} - \frac{6}{5}(x+1)^{5/2}) =$
$= e^{-x} (D_1 + D_2x + \frac{4}{5}(x+1)^{5/2})$

$y_{о.н.}(0) = 1 \cdot (D_1 + 0 + \frac{4}{5}) = D_1 + \frac{4}{5}$
$y_{о.н.}' = -e^{-x}(D_1 + D_2 x + \frac{4}{5}(x+1)^{5/2}) + e^{-x}(D_2 + 2(x+1)^{3/2})$
$y_{о.н.}'(0) = -1 \cdot (D_1 + 0 + \frac{4}{5}) + 1 \cdot (D_2 + 2) = -D_1 + D_2 + \frac{6}{5}$

$\begin{cases} D_1 + \frac{4}{5} = \frac{4}{5} \\ -D_1 + D_2 + \frac{6}{5} = 2 \end{cases}$

$\begin{cases} D_1 = 0 \\ 0 + D_2 + \frac{6}{5} = 2 \end{cases}$

$\begin{cases} D_1 = 0 \\ D_2 = \frac{4}{5} \end{cases}$

$y = \frac{4}{5} x e^{-x} + \frac{4}{5} (x+1)^{5/2} e^{-x} = \frac{4}{5} e^{-x} (x + (x+1)^{5/2})$

## Задача 2 (КР 3)

$\begin{cases} y'' - 2y' + 2y = 4e^x\cos x \\ y(\pi) = \pi e^\pi \\ y'(\pi) = e^\pi \end{cases}$

**Соотв ОЛДУ:**
$y'' - 2y' + 2y = 0$
$\lambda^2 - 2\lambda + 2 = 0$
$(\lambda - (1 + i))(\lambda - (1 - i)) = 0$
$\lambda_{1,2} = 1 \pm i$

**ФСР:**  $e^x \cos x, e^x \sin x$
$y_{о.о.} = C_1 e^x \cos x + C_2 e^x \sin x$

**Возвр к НЛДУ:**
$f(x) = 4e^x\cos x = e^{1x}(4\cdot\cos(1x) + 0\cdot\sin(1x))$
$\alpha = 1, \beta = 1, P(x) = 4, Q(x) = 0$
$\alpha + \beta i = 1 + i \Rightarrow S = 1$
$\text{deg}(R) = \text{deg}(T) = \max\{\text{deg}(P), \text{deg}(Q)\} = 0$
$R(x) = A$
$T(x) = B$

$y_{ч.н.} = x^1 e^{1x} (A\cos 1x + B\sin 1x) = e^x (Ax\cos x + Bx\sin x)$

$y_{ч.н.}'' - 2y_{ч.н.}' + 2y_{ч.н.} = 4e^x\cos x$

$y_{ч.н.}' = (e^x (Ax\cos x + Bx\sin x))' =$
$= e^x ((A + Ax + Bx)\cos x + (B + Bx - Ax)\sin x)$

$y_{ч.н.}'' = (e^x ((A + Ax + Bx)\cos x + (B + Bx - Ax)\sin x))' =$
$= e^x ((A + Ax + Bx)\cos x + (B + Bx - Ax)\sin x) +$
$+ e^x ((A + B)\cos x - (A + Ax + Bx)\sin x +$
$+ (B - A)\sin x + (B + Bx - Ax)\cos x) =$
$= e^x ((A + Ax + Bx + A + B + B + Bx - Ax)\cos x +$
$+ (B + Bx - Ax - A - Ax - Bx + B - A)\sin x) =$
$= e^x ((2A + 2B + 2Bx)\cos x + (2B - 2A - 2Ax)\sin x)$

**Подставим:**
$y_{ч.н.}'' - 2y_{ч.н.}' + 2y_{ч.н.} = 4e^x\cos x$

$e^x (2A + 2B + 2Bx)\cos x + e^x (2B - 2A - 2Ax)\sin x -$
$-2(e^x (A + Ax + Bx)\cos x + e^x (B + Bx - Ax)\sin x) + 2(e^x (Ax\cos x + Bx\sin x)) =$
$= 4e^x\cos x$

$e^x (2A + 2B + 2Bx - 2A - 2Ax - 2Bx + 2Ax)\cos x +$
$+ e^x (2B - 2A - 2Ax - 2B - 2Bx + 2Ax + 2Bx)\sin x = 4e^x\cos x$

$e^x (2B\cos x - 2A\sin x) = 4e^x\cos x + 0 \cdot e^x\sin x$

$\begin{cases} 2B = 4 \\ -2A = 0 \end{cases} \Leftrightarrow \begin{cases} B = 2 \\ A = 0 \end{cases}$

$y_{ч.н.} = 2x e^x \sin x$

$y_{о.н.} = y_{о.о.} + y_{ч.н.}$
$y_{о.н.} = C_1 e^x \cos x + C_2 e^x \sin x + 2x e^x \sin x$

$y_{о.н.}(\pi) = C_1 e^\pi \cos \pi + C_2 e^\pi \sin \pi + 2\pi e^\pi \sin \pi = -C_1 e^\pi$
$y_{о.н.}' = C_1 e^x \cos x - C_1 e^x \sin x + C_2 e^x \sin x +$
$+ C_2 e^x \cos x + 2e^x \sin x + 2xe^x \sin x + 2xe^x \cos x$
$y_{о.н.}'(\pi) = -C_1 e^\pi - C_2 e^\pi - 2\pi e^\pi = (-C_1 - C_2 - 2\pi)e^\pi$

$\begin{cases} -C_1 e^\pi = \pi e^\pi \\ (-C_1 - C_2 - 2\pi)e^\pi = e^\pi \end{cases}$

$\begin{cases} -C_1 = \pi \\ -C_1 - C_2 - 2\pi = 1 \end{cases}$

$\begin{cases} C_1 = -\pi \\ \pi - C_2 - 2\pi = 1 \end{cases}$

$\begin{cases} C_1 = -\pi \\ C_2 = -\pi - 1 \end{cases}$

$y = -\pi e^x \cos x + (-\pi - 1) e^x \sin x + 2x e^x \sin x =$
$= e^x ((2x - \pi - 1)\sin x - \pi \cos x)$


## Указание: 

Указание: на контрольной работе, если к НЛДУ можно применить метод неопределенных коэффициентов, то это НЛДУ не просто можно, а НУЖНО решать именно этим методом‼! Иначе задача не засчитается‼!
  
От вас, в обязательном порядке, требуется знание метода неопределенных коэффициентов и умение распознавать ситуации, когда он применим, а когда – нет‼! Только если метод неопределенных коэффициентов неприменим, только тогда решаете НЛДУ методом вариации постоянных (и этот метод, разумеется, тоже надо знать)‼!
  
В задачах на метод неопределенных коэффициентов может быть любая правая часть, подпадающая под понятие специального вида (как, в самом общем случае, может выглядеть правая часть специального вида, разобрано на практике).
  
В задачах на метод вариации постоянных вид правой части вообще ничем не ограничен. Как следствие, надо уметь считать интегралы от функций разного вида, знать таблицу производных и интегралов, владеть приемами и методами вычисления неопределенных интегралов.
