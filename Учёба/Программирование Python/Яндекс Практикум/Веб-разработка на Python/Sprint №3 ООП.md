## <font color="#FFD473">Объекты и классы</font>
### <font color="#FFB100">Введение. ООП</font>

**ООП** (Объектно-ориентированное программирование) - парадигма программирования, основанная на четырёх принципах: полиморфизм, инкапсуляция, абстракция, наследование.

1. **Инкапсуляция** - позволяет работать с функциями/классами без прямого вмешательства в её устройство. 
2. **Наследование** - одни классы наследуют атрибуты и методы от других.
3. **Полиморфизм** - разные объекты из разных классов выполняют разные действия по своему. 
4. **Абстракция** - выделение важных характеристик объекта.

### <font color="#FFB100">Классы и объекты в Python</font>

Почти всё в Python — классы или объекты какого-то класса.
Для проверки класса сущности в питоне можно использовать функцию `type()`

> [!info] 
> Объект класса часто называют **экземпляром класса**. В курсе будут использоваться оба понятия.

**Атрибут** - характеристика объекта. Одним из атрибутов у объектов является принадлежность к какому-либо классу. Такой атрибут называется `__class__`. Обращаться к нему можно с помочь точечной нотации: `имя_объекта.атрибут`

**Метод** - функция, связанная с объектом. 
Виды использования методов:
1. `класс_объекта.метод(имя_объекта)`
2. `имя_объекта.метод()`

[Документация на методы строк в Питоне](https://docs.python.org/3.9/library/stdtypes.html#string-methods)

**Специальные (магические) методы и атрибуты** - методы и атрибуты, которые выделяются двойными нижними подчёркиваниями с обоих сторон: `__название__`

Пример методы: `__add()__`, такой метод есть у всех классов и объектов, определяет логику `+`, для чисел - сложение, для строк - конкатенация.

### <font color="#FFB100">Собственные классы и объекты</font>

Для создания класса используется ключевое слово `class` и имя класса в стиле *CamelCase* :

```python
class ИмяКласса:
	# Тело класса
```

<u>Имена классам принято давать по правилам:</u>
- Пишите имя класса на английском и с большой буквы.
- Если имя класса состоит из нескольких слов, используйте _CamelCase_ (англ. «ВерблюжийРегистр», также «ГорбатыйРегистр», «СтильВерблюда»), то есть каждое слово пишите с большой буквы, между словами не используйте пробелы или подчёркивания.
- Часто классы — это концепции из реального мира, поэтому выбирайте для их названий существительные.
- Выбирайте понятные и информативные имена. Они должны отражать назначение класса.
- Старайтесь избегать аббревиатур или неочевидных сокращений, если они не общеприняты.
- Не используйте имена, которые уже заняты встроенными типами или классами в Python.

Для создания объекта класса используется: `имя_объекта = класс_объекта()`
```python
class Phone:
    pass


# Создать экземпляр класса Phone().
my_phone = Phone()
```

### <font color="#FFB100">Атрибуты класса и объекта</font>

Атрибуты класса указываются  в теле самого класса, обращаться  к ним можно через точечную нотацию.

```python
class Phone:
    line_type = 'проводной'


rotary_phone = Phone()
keypad_phone = Phone()

# Печать содержимого атрибута line_type через объект rotary_phone.
print(rotary_phone.line_type)
# Печать содержимого атрибута line_type через объект keypad_phone.
print(keypad_phone.line_type)

# Выведется:
# проводной
# проводной
```

Магический метод `__init__` позволяет при создания объекта класса определить значения атрибутов у  этого класса. 

При создания объекта под капотом в Python запускается "конструктор класса", состоящий из двух этапов:
1. Магический метод `__new__`  **создаёт** новый экземпляр класса (=объект)
2.  Магический метод `__init__` **инициализирует** объект — устанавливает для него значения атрибутов, переданных в конструктор класса.

> [!info]
> **Создание объекта** выполняется магическим методом `__new__`. Как правило, при работе с классами его почти никогда не описывают явно: в большинстве случаев вполне достаточно того, как этот метод работает под капотом.

Магически метод `__init__`, как и любые другие методы объявляется вот так:

```python
class ИмяКласса:
    # Тут можно указать атрибуты класса.
    ...

    # Тут объявлен метод, в скобках указываются параметры.
    def имя_метода(self, ...):
        # Тут можно описать тело метода.
        ...
```

Первым параметром в методы экземпляра всегда передаётся параметр `self` (англ. «сам»). `self` — это указатель на объект, создаётся.

Атрибуты, значения которых зависит от инита, записываются внутрь самого инита:

```python
class Phone:

    line_type = 'проводной'

    def __init__(self, dial_type_value):
        self.dial_type = dial_type_value


# Создать объект rotary_phone со значением dial_type_value,
# равным 'дисковый'.
rotary_phone = Phone(dial_type_value='дисковый')
# Создать объект keypad_phone со значением dial_type_value,
# равным 'кнопочный'.
keypad_phone = Phone(dial_type_value='кнопочный')
```

Таким образом выглядит конструкция:

```python
class ИмяКласса:

    атрибут_класса = 'значение_атрибута_класса'

    def __init__(self, значение_атрибута_объекта):
        self.атрибут_объекта = значение_атрибута_объекта
        self.атрибут_объекта = 'значение_атрибута_объекта'
        
```

> [!info]
> Когда при создании объекта передаётся значение атрибута — иногда говорят «передать значение атрибута в инит» или «передать значение атрибута в конструктор класса». Это нормальный рабочий сленг, однако не дайте сбить себя с толку: метод `__init__` — это не конструктор класса, а лишь его часть.

Замена значения атрибута объекта происходит следующим образом:
`Объект_класса.атрибут_объекта = новое_значение_атрибута`

Замена значения атрибута класса происходит следующим образом:
`Имя_класс.атрибут_класса = новое_значение_атрибута`

При этом, если сделать так:
`Объект_класса.атрибут_класса = новое_значение_атрибута`
То значение атрибуту класса поменяется только для данного объекта, а изначальное значение атрибута класса останется прежним и будет присваиваться всем новым объектам класса.
### <font color="#FFB100">Методы объекта</font>

Метод класса объявляется сразу после инициализатора следующим образом:

```python
class ИмяКласса:

    атрибут_класса = 'значение_атрибута_класса'

    def __init__(self, значение_атрибута_объекта):
        self.атрибут_объекта = значение_атрибута_объекта
        self.атрибут_объекта = 'значение_атрибута_объекта'
    
	def ИмяМетода(self, параметр1, параметр2, ...):
		# Логика_метода
```

Вызов метод: `Имя_объекта.ИмяМетода()`
В скобочки вписываются параметры, при этом параметр self указывается автоматические Python'ом.
