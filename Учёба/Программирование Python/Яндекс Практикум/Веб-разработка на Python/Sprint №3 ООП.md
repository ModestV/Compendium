### <font color="#FFB100">Введение. ООП</font>

**ООП** (Объектно-ориентированное программирование) - парадигма программирования, основанная на четырёх принципах: полиморфизм, инкапсуляция, абстракция, наследование.

1. **Инкапсуляция** - позволяет работать с функциями/классами без прямого вмешательства в её устройство. 
2. **Наследование** - одни классы наследуют атрибуты и методы от других.
3. **Полиморфизм** - разные объекты из разных классов выполняют разные действия по своему. 
4. **Абстракция** - выделение важных характеристик объекта.

### <font color="#FFB100">Классы и объекты в Python</font>

Почти всё в Python — классы или объекты какого-то класса.
Для проверки класса сущности в питоне можно использовать функцию `type()`

> [!info] 
> Объект класса часто называют **экземпляром класса**. В курсе будут использоваться оба понятия.

**Атрибут** - характеристика объекта. Одним из атрибутов у объектов является принадлежность к какому-либо классу. Такой атрибут называется `__class__`. Обращаться к нему можно с помочь точечной нотации: `имя_объекта.атрибут`

**Метод** - функция, связанная с объектом. 
Виды использования методов:
1. `класс_объекта.метод(имя_объекта)`
2. `имя_объекта.метод()`

[Документация на методы строк в Питоне](https://docs.python.org/3.9/library/stdtypes.html#string-methods)

**Специальные (магические) методы и атрибуты** - методы и атрибуты, которые выделяются двойными нижними подчёркиваниями с обоих сторон: `__название__`

Пример методы: `__add()__`, такой метод есть у всех классов и объектов, определяет логику `+`, для чисел - сложение, для строк - конкатенация.

### <font color="#FFB100">Собственные классы и объекты</font>

Для создания класса используется ключевое слово `class` и имя класса в стиле *CamelCase* :

```python
class ИмяКласса:
	# Тело класса
```

<u>Имена классам принято давать по правилам:</u>
- Пишите имя класса на английском и с большой буквы.
- Если имя класса состоит из нескольких слов, используйте _CamelCase_ (англ. «ВерблюжийРегистр», также «ГорбатыйРегистр», «СтильВерблюда»), то есть каждое слово пишите с большой буквы, между словами не используйте пробелы или подчёркивания.
- Часто классы — это концепции из реального мира, поэтому выбирайте для их названий существительные.
- Выбирайте понятные и информативные имена. Они должны отражать назначение класса.
- Старайтесь избегать аббревиатур или неочевидных сокращений, если они не общеприняты.
- Не используйте имена, которые уже заняты встроенными типами или классами в Python.

Для создания объекта класса используется: `имя_объекта = класс_объекта()`
```python
class Phone:
    pass


# Создать экземпляр класса Phone().
my_phone = Phone()
```
