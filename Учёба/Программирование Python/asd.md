#### <font color="#FFB100">Что такое протокол</font>

- Машина - компьютер на сленге программистов.
- Сервер - специальная машина, существующая для хранения информации и обработки запросов от клиентов.
- Клиент - браузер на машинах пользователей.
- Протоколы  -  договорённость, которая определяет, как машины общаются друг с другом.
- HTTP (HyperText Transfer Protocol) - самый популярный протокол, используемый для передачи веб-страниц и других объектов в интернете.
- Адрес сайта в интернете начинается с http или https, где https - безопасная версия.
- Веб-страницы и другие объекты в интернете имеют особые имена - URL.
- Браузер преобразует запрос пользователя в HTTP-запрос, который отправляется серверу.
- Сервер выполняет действия и возвращает HTTP-ответ, который представляет собой веб-страницу с результатами поиска.
