 - CPU - повар, RAM - рабочий стол повара, HDD - склад для повара
- Примеры команд, которые поддерживает процессор:
1. MOV - Загружает данные из RAM
2. DIV - Делит
3. SUM - Сумма
4. INC - Увеличивает на единицу
5. XOR - какая-то логическая команда...
6. AND - Логическая И
7. OR - Логическая ИЛИ
- Все действия сводятся к базовым операциям ↑, а базовые операции сводятся к работе с нулями и единицами
### <font color="#9F3ED5">Работа CPU & RAM</font>

RAM:
1. Энергозависимая
2) Быстрый и эффективный рандомный доступ
3) Дорогая (по сравнению с HDD) => малый объем

SSD, HDD:
1) Медленная память
2) Последовательный доступ*
3) Не зависит от энергии
4) Дешевая => большой объем

Оперативную память удобно представить в виде таблицы:

|      | 7   | 6   | 5   | 4   | 3   | 2   | 1   | 0   |
| ---- | --- | --- | --- | --- | --- | --- | --- | --- |
| 0x0  |     |     |     |     |     |     |     |     |
| 0x8  |     |     |     |     |     |     |     |     |
| 0x16 |     |     |     |     |     |     |     |     |
| 0x24 |     |     |     |     |     |     |     |     |

```mermaid
flowchart LR

    %% Системный блок
    subgraph SB["Системный блок"]
        direction TB

        subgraph MB["Материнская плата"]
            direction TB

            CPU["CPU"]
            RAM["RAM"]
            VC["Videocard и т.д."]
            HDD["HDD"]

            CPU --- RAM
            VC --- HDD
        end
    end

    %% Увеличенная схема CPU
    subgraph CPU2["CPU - Central Processing Unit"]
        direction LR

        subgraph LEFT["Внутренние блоки"]
            direction TB
            ALU["ALU - Арифметико-логическое устройство"]
            CU["Управляющее устройство"]
        end

        subgraph REG["Регистры"]
            direction TB
            R1["Регистр 1"]
            R2["Регистр 2"]
            R3["Регистр 3"]
        end
    end

    CPU -.-> CPU2

    style SB fill:#dfeee3,stroke:#444
    style MB fill:#dfeee3,stroke:#444,stroke-width:2px

    style CPU fill:#ff6b6b,stroke:#222,stroke-width:2px,color:#fff
    style RAM fill:#eef7ef,stroke:#444
    style VC fill:#eef7ef,stroke:#444
    style HDD fill:#eef7ef,stroke:#444

    style CPU2 fill:#efc1c1,stroke:#444,stroke-width:2px
    style ALU fill:#9ec9eb,stroke:#444,stroke-width:2px
    style CU fill:#9ec9eb,stroke:#444,stroke-width:2px

    style R1 fill:#f7e08a,stroke:#444
    style R2 fill:#f7e08a,stroke:#444
    style R3 fill:#f7e08a,stroke:#444
```

- ALU - набор устройств на процессоре, способных выполнять логические команды.
- Управляющее устройство - преобразует команды из RAM в команды для ALU.
- Регистр - небольшой набор ячеек памяти.
- Значения в ячейках памяти = адреса каких-то ячеек памяти
### <font color="#9F3ED5">Хранение данных в памяти</font>
- Кодировка - набор правил, по которому происходит шифрование/кодирование символов в двоичный код
- Массивы (Листы) - последовательно выделенная область памяти.
