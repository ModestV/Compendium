## 2. Теоретическая часть

### 2.1 Магнитное поле Земли
- Земля окружена магнитным полем, важным для навигации и геологоразведки.
- Вектор магнитной индукции **B** характеризует магнитное поле в каждой точке.
- Вектор **B** можно разложить на:
  - горизонтальную составляющую **Bₕ**
  - вертикальную составляющую **Bᵥ**  
- Магнитный момент Земли наклонён на 11,5° к оси вращения (см. рисунок 1, стр. 3):contentReference[oaicite:2]{index=2}.

### 2.2 Электромагнитная индукция
- В контуре при изменении магнитного потока возникает ЭДС индукции (закон Фарадея):  
  \[
  \varepsilon_i = -\frac{d\Phi}{dt}
  \]  
- Поток магнитного поля:  
  \[
  \Phi = \int B \cdot dS = B S \cos\alpha
  \]  
  где **S** — площадь рамки, α — угол между нормалью к рамке и вектором B.  
- Для катушки с **N** витками:  
  \[
  \Phi = N B S \cos \alpha
  \]  
- Если катушка вращается с угловой скоростью ω, ЭДС изменяется по гармоническому закону:  
  \[
  \varepsilon_i = N B S \omega \sin (\omega t)
  \]
:contentReference[oaicite:3]{index=3}.

### 2.3 Метод измерения составляющих магнитного поля
- Используется **индуктор** — плоская катушка с большим числом витков, вращающаяся вокруг фиксированной оси.
- Для измерения **Bₕ**: вращение вокруг **вертикальной оси** (рис. 5, стр. 10).  
- Для измерения **Bᵥ**: вращение вокруг **горизонтальной оси** (рис. 6, стр. 10).  
- ЭДС индукции компенсируется постоянной разностью потенциалов на участке цепи, фиксируемой нуль-гальванометром (рис. 4, стр. 9):contentReference[oaicite:4]{index=4}.

### 2.4 Расчет магнитной индукции
- Формула для проекции вектора **B**:
\[
B = \frac{I r T}{4 d^2 N}
\]  
где:
  - **I** — ток через индуктор  
  - **r** — сопротивление участка  
  - **T** — период вращения  
  - **d** — сторона квадрата катушки  
  - **N** — число витков:contentReference[oaicite:5]{index=5}.

### 2.5 Погрешности измерений
- Полная погрешность учитывает систематическую и случайную ошибки:
\[
\gamma = \sqrt{\left(\frac{\Delta I}{I}\right)^2 + \left(\frac{\Delta r}{r}\right)^2 + \left(2 \frac{\Delta d}{d}\right)^2 + \left(\frac{\Delta T}{T}\right)^2}
\]  
- Абсолютная погрешность:
\[
\Delta B = \gamma \cdot B
\]  
- Формулы для систематической и случайной погрешности — стр. 12–14:contentReference[oaicite:6]{index=6}.
